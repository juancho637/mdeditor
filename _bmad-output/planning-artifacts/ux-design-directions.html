1. Notion Classic

Layout limpio con sidebar prominente y máxima prioridad al contenido. Inspirado directamente en la elegancia y simplicidad de Notion. El sidebar es la columna vertebral de la navegación, y el contenido respira con márgenes amplios.

Sidebar prominente Contenido centrado Márgenes amplios Navegación clara

Fortaleza

Navegación intuitiva para equipos con muchos documentos. La jerarquía de carpetas es visible y clara.

Ideal para

Diego consultando documentos y navegando entre carpetas de proyectos.

Referente

Notion — sidebar con tree view, contenido limpio centrado.

Product Brief: markdown
Última edición por Carlos · hace 2 horas · 3 colaboradores
Resumen Ejecutivo
Markdown es una plataforma web colaborativa de edición de documentos en markdown, diseñada para equipos pequeños que necesitan una fuente única de verdad para su documentación.
Visión Central
Declaración del Problema
Los equipos pequeños multidisciplinarios generan cada vez más documentación a través de herramientas de IA en formato markdown. Sin embargo, compartir y colaborar sobre estos documentos es un proceso fragmentado.
  • Pérdida de cambios entre versiones locales
  • Versiones desactualizadas generan desalineación
  • Solo los miembros técnicos pueden editar markdown
    • Solución Propuesta
    Una aplicación web self-hosted con tres modos de interacción, donde todo el contenido es markdown por debajo, complementado con colaboración en tiempo real e integración MCP.

    2. HackMD Focus

    Editor-first con el split view como protagonista. El toolbar de markdown siempre visible y accesible. Optimizado para la experiencia de edición, especialmente en modo híbrido. El sidebar se mantiene compacto para dar máximo espacio al editor.

    Editor protagonista Split view central Toolbar siempre visible Sidebar compacto

    Fortaleza

    La experiencia de edición más potente. Valentina ve inmediatamente el resultado de cada acción del toolbar.

    Ideal para

    Valentina editando con toolbar + preview simultáneo. Carlos escribiendo markdown puro.

    Referente

    HackMD — split view con toolbar funcional y sync scroll.

    • 3. Minimal Zen

    Ultra minimalista. El sidebar está oculto por defecto y todo el espacio es para el documento. La interfaz desaparece completamente — solo queda el contenido. El header se reduce al mínimo posible. Modo de concentración total.

    Sidebar oculto Full-width contenido Chrome mínimo Modo concentración

    Fortaleza

    Máxima inmersión en el contenido. Cero distracciones. La herramienta realmente desaparece.

    Ideal para

    Carlos escribiendo concentrado. Diego leyendo documentos largos sin distracciones.

    Referente

    iA Writer, Typora — editores que priorizan el contenido sobre la interfaz.

    • 4. Dashboard Pro

    Header más robusto con breadcrumbs prominentes, barra de búsqueda siempre visible, y sidebar con búsqueda integrada. Diseñado para equipos que manejan muchos documentos y necesitan acceso rápido a todo. Prioriza la eficiencia de navegación.

    Header robusto Búsqueda prominente Sidebar con filtros Navegación eficiente

    Fortaleza

    Máxima eficiencia para encontrar y navegar entre documentos. Búsqueda siempre a un clic.

    Ideal para

    Equipos con cientos de documentos que necesitan encontrar información rápido.

    Referente

    Confluence + Linear — navegación robusta con búsqueda integrada.

    5. Collaborative First

    La presencia de usuarios como elemento central. Avatares, actividad reciente, y estado de edición siempre visibles. El panel de historial integrado muestra quién está haciendo qué. Diseñado para que la colaboración sea el protagonista visual.

    Presencia central Historial integrado Actividad visible Cursor de IA

    Fortaleza

    La colaboración se siente como una experiencia social. Siempre sabes quién está haciendo qué.

    Ideal para

    Equipos que colaboran frecuentemente en tiempo real. Sesiones de edición conjunta.

    Referente

    Figma — presencia de usuarios como feature principal, no secundaria.

    6. Hybrid Smart

    Combinación inteligente de todas las direcciones. El sidebar de Notion, el split view de HackMD, la presencia de Figma, y la limpieza del Minimal Zen. La interfaz se adapta según el modo activo: en preview es minimalista, en híbrido muestra toolbar y split, en editor maximiza el espacio de código.

    Lo mejor de cada uno Adaptativo por modo Equilibrio perfecto Diseño inteligente

    Fortaleza

    Cada modo tiene su propia personalidad optimizada, pero se sienten parte de la misma app.

    Ideal para

    Los 3 perfiles simultáneamente. Cada uno usa su modo ideal sin comprometer la experiencia de los demás.

    Referente

    Notion + HackMD + Figma — lo mejor de cada uno, combinado inteligentemente.
